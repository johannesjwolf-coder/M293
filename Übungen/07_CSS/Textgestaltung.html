Textgestaltung mit HTML & CSS

Diese Seite zeigt Überschriften, Auszeichnungen, Listen, Links und verschiedene Schriften.

1. Grundlagen

HTML liefert die Struktur, CSS macht das Design. Du kannst Text z.B. kursiv, fett oder markiert darstellen. (Dies ist ein kleinerer Hinweistext.)

Ein Beispiel für <code>: p { font-size: 16px; }

„Gute Typografie macht Inhalte leichter verständlich.“

Textauszeichnungen

  • strong = wichtig / fett
  • em = betont / kursiv
  • mark = Hervorhebung
  • code = Code-Schrift

Link-Beispiel: HTML-Doku (MDN)

Serif
Schrift mit kleinen „Füsschen“ (z.B. Merriweather).
Sans-Serif
Schrift ohne „Füsschen“ (z.B. Inter).

Tipp: Nutze line-height und max-width, damit Text angenehm zu lesen ist.
